# Isekai API — maven repository

This branch is a plain maven repository layout, served over `raw.githubusercontent.com`.
It is generated by `./gradlew publish` on `main`; do not edit it by hand.

```gradle
repositories {
    maven { url = "https://raw.githubusercontent.com/KURONAMI333/isekai-api/maven" }
}
dependencies {
    compileOnly "com.kuronami.isekaiapi:isekai_api:2.0.0"
}
```

The published pom declares no dependencies: consumers bring their own NeoForge.
Source, issues and documentation live on [`main`](https://github.com/KURONAMI333/isekai-api).
